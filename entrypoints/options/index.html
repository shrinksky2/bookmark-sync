Bookmark Sync

账号

选择同步方式，并配置对应的远程存储。
需要勾选 gist 权限。
Gist 地址：
· 首次使用：填 Token → 点"创建 Gist" → 保存
· 其他设备：填同一个 Token 和 Gist ID → 保存
填到目录为止，末尾带或不带 / 均可，插件会自动拼接 bookmarks.json。
建议先用"测试连接"确认配置正确，再保存。

同步

配置自动同步的间隔与开关。
建议 30 分钟以上。最小值为 1 分钟，浏览器不允许更短的周期。
开启后，浏览器会按上面的间隔自动同步书签。

数据

导出书签用于备份或迁移，或从文件恢复书签。

导出

将当前本地书签保存为文件。
· HTML：浏览器通用格式，可导入 Chrome / Edge / Firefox
· JSON：完整格式，保留所有字段，用于本插件恢复
